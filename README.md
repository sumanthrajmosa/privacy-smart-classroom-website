# Privacy-Preserving Smart Classroom — Project Website

A responsive static website for the project **Privacy-Preserving Smart Classroom Occupancy Detection and Energy Management**.

## Files
- `index.html` — complete website (HTML, CSS, and inline layout styles).
- `Privacy_Preserving_Smart_Classroom_User_Study_Report.pdf` — add the generated report PDF to this folder so the report link works.

## Run locally
Open `index.html` in a browser.

## Deploy on Vercel
1. Create a GitHub repository for this website.
2. Upload `index.html`, `README.md`, and the report PDF.
3. In Vercel, choose **Add New → Project** and import the GitHub repository.
4. Framework preset: **Other**. Build command: leave blank. Output directory: `.`.
5. Deploy.

## Before publishing
- Replace or add team member names and guide details if required.
- Confirm the public GitHub URL and report filename.
- The dashboard/floorplan is an illustrative mockup, not a live camera feed.
- Survey statistics reflect the provided spreadsheet. They represent responses/preferences, not measured accuracy or energy savings.
- Only publish a dataset or survey summary that excludes identifying personal information.
